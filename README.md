# Python for Psychological Inquiry — Course Syllabus Website

A responsive and academically styled syllabus website built using HTML and CSS for a BSc Psychology course titled **"Python for Psychological Inquiry"**.

This project presents a structured, interactive curriculum document with sidebar navigation, collapsible session cards, responsive layouts, and print-friendly formatting.

---

## ✨ Features

- Responsive sidebar navigation
- Interactive expandable session cards
- Academic visual design using custom CSS variables
- Mobile-friendly layout
- Print-optimized formatting
- Structured curriculum sections and units
- Typography using Google Fonts
- Clean semantic HTML structure

## 💻 Running Locally

Simply open:

```bash
index.html
```

in your browser.

Or use VS Code with the Live Server extension:

1. Open project folder
2. Right-click `index.html`
3. Select **Open with Live Server**
